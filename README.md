# Study Sphere 📚☁️

**Study Sphere** is a cloud-based Android application designed to centralize academic resources, campus activities, and student club management into a single platform. It improves communication between students, faculty, and administrators through real-time updates and secure cloud storage.

## 🚀 Features
- Secure user authentication with role-based access (Student / Faculty / Admin)
- Academic material sharing (notes, assignments, timetables)
- Campus events and club activity management
- Real-time notifications and updates
- Cloud-based storage and synchronization
- Clean and user-friendly Android UI

## 🛠️ Tech Stack
- **Frontend:** Android (Java, XML)
- **Backend:** Firebase
  - Firebase Authentication
  - Cloud Firestore
  - Firebase Storage
- **Tools:** Android Studio, Git, GitHub

## 👥 User Roles
- **Students:** View/download materials, receive notifications, participate in clubs
- **Faculty:** Upload notes, assignments, notices, and manage events
- **Admin:** Manage users, verify roles, oversee academic and campus data

## 🏗️ Architecture
- Android client application
- Firebase Authentication for secure login
- Firestore for real-time database
- Firebase Storage for file uploads

## 🔐 Security
- Role-based access control
- Email domain verification
- Secure cloud data storage

## 📈 Future Enhancements
- Push notifications using Firebase Cloud Messaging
- In-app chat and discussion forums
- Web-based version
- Analytics dashboard
- Offline access support
